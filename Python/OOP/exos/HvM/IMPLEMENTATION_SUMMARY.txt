   - 4d6 best-3 pour Force/Endurance
   - 1d4 pour dégâts

✅ Système de modificateurs
   - < 5: -1
   - 5-9: 0
   - 10-14: +1
   - ≥ 15: +2

✅ Calcul des points de vie
   - PV = Endurance + Modificateur(Endurance)

✅ Mécanique de frappe
   - Dégâts = 1d4 + Modificateur(Force)
   - Minimum 1 dégât garantis

✅ Héros (2 types)
   - Human: +1 Force, +1 Endurance

✅ Monstres (3 types)
   - Wolf: Leather (1d4)

   - Dragonlet: +1 Endurance, Gold + Leather

✅ Combat

   - Mort si PV ≤ 0
